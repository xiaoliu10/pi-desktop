# 输入框能力

- 「+」菜单：搜索并选择项目文件、通过原生文件选择器添加文档、选择本地已启用技能。技能显示 SKILL.md 中的名称和说明。
- 所选内容显示为可移除标签；发送时把文件文字/技能内容、来源路径与用户输入一起传给 pi。文件内容是选择时的快照，修改源文件后应重新添加。发送失败恢复输入与附件。
- 文档支持 PDF 文字提取、DOCX、Markdown、普通文本和代码；不支持扫描 PDF OCR、旧版 DOC、图片附件和表格/演示文档解析。每个文件最多 10 MiB / 60000 字符，一次选择最多 10 个，组合消息最多 190000 字符；超过限制明确提示，不截断。
- 项目上下文只读取所选项目内的文件，阻止通过符号链接越界；列表排除 node_modules、构建目录及常见隐藏配置，最多索引 2000 个文件。项目目录和 Git 分支显示在输入框上方；新任务可选目录，已有任务固定项目。分支仅展示，不切换分支。
- 模型可在首次发送前选择，发送前应用模型及预选思考等级；运行中禁止修改。活动任务通过 get_available_thinking_levels / set_thinking_level / get_state 显示和更新实际可用等级，包括模型支持时的 xhigh（最高）。尚未启动的任务根据模型 reasoning 配置提供保守的预选列表，运行时以 pi 返回值为准。
- pi 兼容范围：0.85.1、0.86.0（POSIX）；本次使用 0.86.0 和本地 SSE 模型验证，不调用外部模型服务。

验证：pi-composer 测试覆盖真实 PDF/DOCX 提取、文本限制与路径边界；pi-desktop-start 覆盖附件发送/恢复和首次发送前应用模型/思考；pi-integration 覆盖真实 pi 思考设置及原有权限流程。
