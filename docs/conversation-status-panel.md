# 会话状态面板

参考 ZCode `ConversationStatusPanel.tsx` 与 `conversationStatusPanelModel.ts`，按 PI Desktop 的本地会话体系独立实现。

- 聊天右侧紧凑卡片；支持折叠、加宽和手动刷新。查看文件差异时让位于现有右侧工作台。
- Git 统计：当前目录范围相对 HEAD 的已暂存及未暂存净变化。空仓库使用空树基线，未跟踪文件、二进制文件单独计数，不编造行数。运行中每 3 秒、空闲每 10 秒刷新，无并发轮询；切换会话后丢弃旧请求。
- 点击更改打开工作台。分支列表及提交/推送入口把明确请求添加到输入框，由用户发送给 pi 执行；不是原生 Git 一键操作。
- `desktop_update_plan` 是 Desktop 随附的元数据工具，支持 pending / in_progress / completed，最多 30 项。允许计划模式使用，不读写项目文件，也不执行命令。结果由 pi 保存为会话工具消息，实时和历史共用一个清单解析器。
- 只接受成功工具结果，失败、未完成或无效更新不会覆盖清单。无清单的旧会话显示说明，不根据工具次数推断进度。
- 已启动的旧 pi 进程需要重新启动才能加载新增工具。模型根据多步骤任务提示使用工具，简单问答可能不创建清单。

验证：Git 临时仓库测试、计划解析及权限回归 14 项；真实 pi + 本地模型模拟服务验证计划模式暴露工具、调用及历史恢复 1 项；独立 UI 预览验证视觉和折叠；typecheck / build。
